# 🛡️ TRUSTSHIELD AI

### Don't Just Detect Fraud. Detect Manipulation.

**TRUSTSHIELD AI** is an AI-powered proactive banking security platform that detects **fraud, social engineering, unusual customer behaviour, suspicious devices, and fraud networks** before money leaves the customer's account.

🔗 **Live Demo:** https://trustshield-ai-618809265776.asia-southeast1.run.app/

## ✨ Key Features

- 🧠 **Behavioural Profiling** — Detects unusual customer behaviour.
- 💳 **Transaction Intelligence** — Identifies suspicious payment patterns.
- 📱 **Device Intelligence** — Detects new devices and unusual login contexts.
- 🕸️ **Fraud Network Graph** — Identifies connected suspicious accounts.
- 🗣️ **Social-Engineering Detection** — Detects scam and manipulation signals.
- 👤 **Vulnerability-Aware Protection** — Personalised protection without age-based assumptions.
- 🚦 **Adaptive Friction** — Approve, warn, verify, delay, or pause based on risk.
- 🔍 **Explainable AI** — Shows why a transaction is considered risky.
- 👨‍👩‍👧 **Trusted Contact & Human Escalation** — Adds human verification for critical cases.
- 🧪 **Red-Team Simulator** — Simulates real-world banking scam scenarios.

## 🔥 Core Innovation

Traditional fraud detection asks:

> **“Is this transaction suspicious?”**

TRUSTSHIELD asks:

> **“Is this customer being manipulated?”**

### 🛠️ Technology

**React • Vite • FastAPI • Python • PostgreSQL • Neo4j • Machine Learning • AI**

### 🎯 Goal

**Protect customers before the money leaves the account while minimising unnecessary transaction friction.**
